🎯 O que é?
----------

O **Tri-Chat** é uma plataforma onde você pode criar debates entre múltiplos agentes IA, cada um com personalidades e especialidades diferentes. Perfeito para:

* 🧠 Analisar temas complexos sob múltiplas perspectivas
* 📚 Debates acadêmicos e educacionais
* 💼 Análise de casos práticos (direito, contabilidade, etc.)
* 🎭 Simulações e role-playing com IA

✨ Funcionalidades
-----------------

* **🤖 Múltiplos Agentes**: Configure quantos agentes quiser, cada um com personalidade e voz únicas
* **⚡ Debates em Tempo Real**: Streaming SSE para ver as respostas sendo geradas ao vivo
* **🎙️ Text-to-Speech**: Agentes podem "falar" usando OpenAI TTS
* **📊 Dashboard Completo**: Visualize debates, logs, estatísticas
* **🔍 Busca e Filtros**: Encontre debates por título ou status
* **⏹️ Controle Total**: Pare debates em andamento, cancele, gerencie tudo
* **🔐 Autenticação**: Sistema de login com token
* **📱 Interface Responsiva**: Funciona em desktop e mobile

🚀 Como Rodar
------------

### Pré-requisitos

* Node.js >= 18
* API Key da MiniMax (ou OpenAI-compatible)
* API Key da OpenAI (para TTS - opcional)

### Instalação

```
# Clone o repositório
git clone https://github.com/aajunior43/tri-chat.git
cd tri-chat

# Instale as dependências
npm install

# Configure as variáveis de ambiente
# Crie um arquivo .env com:
# MINIMAX_API_KEY=sk-...
# OPENAI_API_KEY=sk-... (opcional, para TTS)
# TRICHAT_TOKEN=seu-token-secreto

# Inicie o servidor
npm start

# Ou em modo desenvolvimento (auto-reload)
npm run dev
```

O servidor estará rodando em: **<http://localhost:18888/tri-chat/>**

📖 Como Usar
-----------

### 1. Primeiro Acesso

Ao acessar pela primeira vez, configure o token de acesso que está no console do servidor.

### 2. Criar Agentes

Crie agentes com diferentes personalidades:

* Nome e avatar
* System prompt (personalidade)
* Cor e voz

### 3. Iniciar Debate

1. Clique em "Novo Debate"
2. Escolha o título e descrição
3. Selecione os agentes que participarão
4. Defina o número de rodadas
5. Envie a pergunta inicial
6. Assista o debate acontecer em tempo real!

### 4. Gerenciar Debates

* **Buscar**: Use a barra de busca para encontrar debates
* **Filtrar**: Filtre por status (Abertos, Em Debate, Finalizados)
* **Parar**: Clique em "⏹ Parar" para interromper um debate em andamento
* **Ver Detalhes**: Clique em um debate para ver todas as mensagens

🏗️ Arquitetura
--------------

```
tri-chat/
├── server.js           # Backend principal (Express + SQLite)
├── public/
│   └── index.html      # Frontend completo (HTML + CSS + JS)
├── package.json        # Dependências e scripts
└── tri-chat.db         # Banco de dados SQLite (criado automaticamente)
```

### Tecnologias

* **Backend**: Node.js + Express 5
* **Banco de Dados**: SQLite (better-sqlite3)
* **IA**: MiniMax API (Anthropic-compatible)
* **TTS**: OpenAI Text-to-Speech
* **Streaming**: Server-Sent Events (SSE)

🔧 API Endpoints
---------------

### Agents

* `GET /tri-chat/api/agents` - Listar agentes
* `POST /tri-chat/api/agents` - Criar agente
* `PUT /tri-chat/api/agents/:id` - Atualizar agente
* `DELETE /tri-chat/api/agents/:id` - Deletar agente

### Tasks (Debates)

* `GET /tri-chat/api/tasks` - Listar debates
* `POST /tri-chat/api/tasks` - Criar debate
* `POST /tri-chat/api/tasks/:id/start` - Iniciar debate
* `POST /tri-chat/api/tasks/:id/cancel` - Cancelar debate
* `GET /tri-chat/api/tasks/:id/messages` - Listar mensagens

### Outros

* `GET /tri-chat/api/stats` - Estatísticas
* `GET /tri-chat/api/logs` - Logs do sistema
* `POST /tri-chat/api/tts` - Gerar áudio TTS
* `GET /tri-chat/api/events` - SSE events (streaming)

🌐 Deploy
--------

### Railway (Recomendado)

O Tri-Chat funciona perfeitamente no Railway:

1. Conecte seu repositório GitHub
2. Adicione as variáveis de ambiente:
   * `MINIMAX_API_KEY`
   * `OPENAI_API_KEY` (opcional)
   * `TRICHAT_TOKEN`
3. Deploy automático!

**Por que Railway?** Suporta processos de longa duração e SQLite nativamente.

### Outras Plataformas

Para Vercel/Netlify/AWS Lambda: **NÃO recomendado** - requer migração para PostgreSQL e arquitetura serverless (debates usam SSE e processos longos).
