# Wendigo Lore

Site informativo sobre a lenda do wendigo, construído como um Zo Site.

## Sobre

O site apresenta:

- **Origem e significado** do wendigo nas tradições Algonquinas (Cree, Ojibwe, Wabanaki)
- **Aparência e características** segundo o folclore original
- **Casos históricos**: registros jesuítas de 1661, Swift Runner (1878–1879) e Jack Fiddler (1907)
- **Relatos modernos** encontrados em fóruns como o Reddit, com ressalvas sobre verificação
- **Cultura pop vs. folclore**: como filmes, séries e jogos reinterpretaram a figura
- **Nota de respeito** sobre a importância cultural do wendigo para povos indígenas

## Tecnologia

- Zo Site com React + TypeScript + Vite + Tailwind CSS
- Tema escuro com acentos em azul-gelo
- Efeito de neve em canvas sobreposto
- Navegação fixa com scroll suave entre seções

## Estrutura

- `src/pages/Home.tsx` — página principal com todas as seções
- `src/App.tsx` — roteamento
- `index.html` — metadados da página
- `public/images/wendigo-hero.png` — ilustração gerada para o hero

## Como visualizar

O site roda automaticamente no ambiente Zo. Use a prévia do site na interface do Zo ou o preview autenticado disponibilizado pela plataforma.
